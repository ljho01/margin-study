# 여백

Tauri 2 + React 19 + TypeScript + shadcn/ui로 만든 로컬 PDF 학습 앱입니다.

## 실행

```sh
bun install --frozen-lockfile
bun run desktop
```

`bun run dev`는 브라우저에서 PDF·필기를 확인하는 개발용 실행입니다. ChatGPT·Claude 구독 연결과 AI 기능은 Tauri 앱에서 동작합니다.

## 사용

1. **폴더 열기**로 작업 폴더를 선택하고 **신뢰하고 열기**를 누릅니다. 왼쪽 파일 트리에서 하위 폴더와 PDF를 탐색합니다. 항목을 우클릭하면 Finder처럼 **이름 변경**과 **휴지통으로 이동**을 할 수 있고, 끌어서 다른 폴더(빈 곳에 놓으면 최상위)로 옮깁니다. 열어 둔 PDF의 이름이나 위치를 바꾸면 저장 경로도 따라가고, 휴지통으로 옮기면 다음 저장 때 위치를 다시 묻습니다. **PDF 열기**로 개별 파일을 열 수도 있습니다.
2. 상단에서 하이라이트, 펜, 글씨 쓰기, 지우개를 선택합니다. 글씨는 원하는 위치를 클릭하면 글자에 맞춰 늘어나는 상자가 뜨고, 입력한 뒤 다른 곳을 클릭하거나 `⌘Enter`를 누르면 그 자리에 남고 선택 도구로 바뀝니다. `Esc`는 작성을 취소합니다. 글씨 도구로 기존 글씨를 클릭하거나 선택 도구에서 더블클릭하면 다시 편집합니다. 선택 도구로 본문 텍스트를 드래그한 뒤 `H`를 누르면 그 줄 범위에 하이라이트가 생깁니다. 텍스트 레이어가 없는 스캔 페이지는 macOS Vision OCR(한국어·영어)로 인식한 뒤 같은 방식으로 선택합니다. 선택 도구(`V`)에서 필기를 클릭하면 선택되고, 끌어서 옮기거나 `Delete`로 지웁니다. 글씨는 더블클릭해 고칩니다. 저장한 뒤 다시 연 필기도 같은 방식으로 편집합니다.
3. **AI 구독 설정**에서 ChatGPT와 Claude 구독을 각각 연결하고 모델을 선택합니다. 두 계정을 함께 연결해 두고 모델만 바꿀 수 있습니다. ChatGPT는 이 Mac의 기존 Codex OAuth 로그인도 연결할 수 있습니다. Claude는 브라우저 OAuth 로그인 후 앱으로 돌아오면 연결되며, 인증 정보는 macOS 키체인에 보관하고 자동 갱신합니다. 각 제공자에 직접 요청하며 API 키는 필요하지 않습니다. 각 구독의 모델 접근 권한·사용 한도가 적용됩니다.
4. 하단 **처리 → 문서 전체**를 누르면 각 페이지의 해설·한국어 번역·핵심 정리를 차례로 저장합니다. 중지 후 다시 실행하면 완료된 페이지를 건너뜁니다.
5. 오른쪽 질문창은 답변을 생성되는 대로 TanStack Markdown으로 표시하며(수식은 KaTeX), AI가 도구로 페이지를 직접 읽습니다. `read_current_page`로 보고 있는 페이지를, `list_pages`로 페이지별 저장된 요약(요약이 없으면 본문 발췌)을 확인한 뒤 `read_page`로 필요한 다른 페이지의 본문과 이미지를 읽고, 참고한 페이지 번호를 답에 밝힙니다. 페이지 번호는 삭제 후 화면에 보이는 번호입니다. 페이지를 이동해도 대화가 섞이지 않습니다.
   답변 중에 보낸 질문은 입력창 위 대기열에 쌓였다가 차례로 전송됩니다. 대기열의 질문은 바로 보내기·수정·삭제할 수 있습니다. ■로 답변을 중지하면 그때까지 쓴 내용이 남고 대기열도 멈춥니다. 답변 아래 **이어서**를 누르면 중단된 지점부터 이어 쓰고 대기열도 다시 진행하며, ▶는 대기열만 다시 진행합니다.
6. `Delete`로 현재 페이지를 삭제합니다. 왼쪽 **페이지** 탭에서 `⌘`-클릭으로 페이지를 하나씩, `⇧`-클릭으로 현재 페이지부터 범위를 고르면(파란색) `Delete`가 고른 페이지들을 삭제합니다. `Esc`로 선택을 해제하고, `⌘Z`로 복원합니다.
7. 수정하면 제목 옆에 점이 표시되고, `⌘S`로 원본 PDF에 저장합니다. 필기는 표준 PDF 주석(Highlight·Ink·FreeText)으로 기록되어 다른 뷰어에서도 보이고, 이 앱에서 다시 열면 편집할 수 있습니다. 임시 파일에 쓴 뒤 교체하며, 연 이후 다른 곳에서 파일이 바뀌었으면 덮어쓰지 않습니다. **사본 내보내기**는 별도 파일로 저장합니다.
8. 상단 테마 메뉴에서 라이트·다크·시스템을 고릅니다.

| 단축키 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 페이지 이동 |
| `Delete` | 페이지 삭제 |
| `⌘S` | 저장 |
| `⌘Z` | 되돌리기 (필기·페이지 삭제) |
| `⌘O` / `⌘⇧O` | PDF 열기 / 폴더 열기 |
| `⌘B` | 탐색기 패널 |
| `⌘J` | 해설 패널 |
| `⌘⇧B` | 질문 패널 열기·닫기 (열면 입력창 포커스) |
| `⌘⌥S` | 새 대화 |
| `⌘W` | 질문 패널에서 작업 중이면 현재 대화 탭 닫기(빈 대화만 남으면 패널 닫기), 그 밖에는 창 최소화. 앱은 종료되지 않으며 `⌘Q`로 종료합니다 |
| `V` `H` `P` `T` `E` | 선택·하이라이트·펜·글씨·지우개 (텍스트 선택 중 `H`는 하이라이트 생성) |

단축키는 TanStack Hotkeys로 처리하며 한글 입력 상태에서도 동작합니다. 입력창·메뉴·대화상자에 포커스가 있으면 페이지 단축키는 무시됩니다.

## 폴더와 디자인

- 신뢰한 폴더만 디렉터리 탐색과 PDF 읽기를 허용합니다. 절대 경로, 상위 경로 이동, 루트 밖 심볼릭 링크는 Rust에서 차단합니다.
- 신뢰 기록은 앱 데이터의 `workspaces.json`에 저장됩니다. 폴더를 다시 열면 펼친 경로와 마지막 PDF를 복원합니다. 원본 파일을 수정하거나 폴더의 코드를 실행하지 않습니다.
- UI는 shadcn 공식 `new-york-v4` 컴포넌트와 neutral 토큰을 사용합니다. 색상·글꼴·컴포넌트 스타일을 별도로 재정의하지 않습니다. PDF 필기 색상은 문서 데이터로 별도 관리합니다.
- 탐색기/PDF/해설/질문 영역의 크기는 구분선을 드래그해 조절합니다.

## 저장 및 인증

- PDF, 필기, 해설, 페이지별 대화는 앱 WebView의 IndexedDB에 저장됩니다. 원본 파일을 옮겨도 문서함의 사본은 열 수 있습니다.
- ChatGPT OAuth와 모델 요청은 공식 Codex app-server의 stdio 프로토콜을 사용합니다. 토큰은 Rust 프로세스에서 관리하며 프런트엔드에 보내지 않습니다.
- 인증 프로필: macOS의 `~/Library/Application Support/com.jaeho.margin-study/codex-profile`. 이 앱에서 로그아웃해도 기존 Codex 프로필은 수정하지 않습니다.
- AI 요청에는 해당 페이지의 이미지와 추출된 본문이 전송됩니다. 문서 전체 처리는 모든 남은 페이지를 차례로 요청하므로 ChatGPT/Codex 구독의 사용 한도가 적용됩니다.
- 모델 목록은 로그인한 계정에서 조회합니다. API 키를 요구하거나 별도의 API 과금으로 전환하지 않습니다.
- 공식 Codex app-server가 변경되면 런타임 갱신이 필요할 수 있습니다. 현재 빌드에는 실행 시 별도 설치가 필요 없도록 Codex 바이너리를 포함합니다.
- 암호화된 PDF는 암호를 해제한 후 가져와야 합니다. AI 해설·채팅은 앱에 저장되며 PDF 파일에는 기록하지 않습니다.

## 빌드 및 검사

```sh
bun run build
bun test
(cd src-tauri && cargo check && cargo test --lib)
# 로컬 macOS 앱 빌드 (배포용 공증과 별개)
APPLE_SIGNING_IDENTITY=- bun run desktop:build --bundles app
```

빌드 전 설치된 `codex` 실행 파일과 같은 배포본의 `codex-code-mode-host`를 런타임으로 복사합니다. 현재 ChatGPT 계정 모델은 도구를 Code Mode로만 노출하므로 질문창의 페이지 도구에 이 호스트가 필요합니다(경로 지정: `MARGIN_CODE_MODE_HOST`). 다른 경로를 사용하려면 `MARGIN_CODEX_BINARY`를 지정하세요. Git에는 실행 파일과 인증 파일을 포함하지 않습니다.

PDF 표시는 PDF.js/react-pdf, PDF 내보내기는 pdf-lib/fontkit, 한국어 내보내기 글꼴은 SIL OFL의 나눔고딕을 사용합니다. 글꼴 라이선스는 `public/fonts/OFL.txt`에 있습니다.

## 릴리스와 자동 업데이트

`main`에 푸시하면 GitHub Actions(`.github/workflows/release.yml`)가 Apple silicon(arm64)용 앱을 빌드하고 Developer ID로 서명한 뒤 Apple 공증을 거쳐 GitHub Release로 배포합니다. 버전은 KST 기준 날짜와 시각입니다(`YYYY.MDD.HMM`, 예: 2026년 10월 17일 17시 05분 → `2026.1017.1705`).

설치된 앱은 실행할 때와 6시간마다 `releases/latest/download/latest.json`을 확인해 새 버전을 백그라운드에서 설치하고, **다시 시작** 알림을 띄웁니다. 업데이트 파일은 Tauri updater 키로 서명되며 앱에 들어 있는 공개키로 검증합니다.

워크플로에 필요한 저장소 Secrets:

| 이름 | 내용 |
| --- | --- |
| `MACOS_CERTIFICATE` | Developer ID Application 인증서와 개인키(.p12, base64) |
| `MACOS_CERTIFICATE_PASSWORD` | .p12 비밀번호 |
| `APPLE_API_KEY` | 공증용 App Store Connect API 키(.p8 내용) |
| `APPLE_API_KEY_ID` | API 키 ID |
| `APPLE_API_ISSUER` | API Issuer ID |
| `UPDATER_PRIVATE_KEY` | `tauri signer generate`로 만든 업데이트 서명 키 |

로컬에서는 `bun run release`가 같은 스크립트(`scripts/release-dmg.sh`)를 notarytool 키체인 프로필로 실행합니다.
